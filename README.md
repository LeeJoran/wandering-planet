# 流浪星球 Wandering Planet

**把一起度过的时间，变成看得见的星。**

一个星空主题的陪伴型 H5 应用：点开一片星空，用「在轨」的时光与留下的文字、声音、照片，逐颗点亮星座；也可以与 1-4 位同行者「共赴」同一片天空，共同点亮 20 座非常见星座。

> 🌟 在线体验：https://leejoran.github.io/wandering-planet/

## 功能

**单人 · 我的天空**
- 片头星星逐一点亮动画 → 整片星空（自由星 + 流星/彗星 + 星尘漂移）
- 在轨计时点亮：关闭页面不丢进度，下次打开自动结算
- 12 星座全量：按官方星图连线的星点布局，逐星点亮 → 弦月态 → 完全点亮 → 官方虚影显现
- 每颗星 / 每个星座的五类卡片：名称与别名 / 信息（星体·亮度·位置）/ 西方故事 / 东方故事 / 观测
- 留言三形态：文字、语音（60 秒）、照片，换算为点亮能量（规则对用户隐藏，只显示百分比）
- 星座点亮庆祝 + 「了解XX座」回顾（每次点亮时间、文字、可播语音、照片）

**共赴 · 多人天空**
- 免登录：点亮信标 → 6 位邀请码/链接 → 对方循光而来
- 一人可同时拥有多段共赴，每段独立删除；邀请码是长期入口
- 2-5 人共赴（信标发出时选人数，内部可切换上限）；3 人以上可自取称呼
- 共赴在轨：任一人在线则计时继续；**全员同在时加成随人数递增**（2 人 ×1.5 → 5 人 ×2）
- 20 座非常见星座（大熊、猎户、天鹅……）共同点亮，与单人同样的星图/轮廓/五类卡片
- 星被点亮后自动顺延下一颗，直到整座点亮 → 双方/全员庆祝弹层
- 留言标注「我/对方/称呼」，对方传来心意实时提示
- 黯淡/复明：这段共赴不是一次性的，随时回来继续点亮

## 技术架构

三层架构，为将来迁移小程序/App 留好口子：

```
src/
├── core/        # 纯 TS 业务层：星座数据、能量系统、模型、仓储（无平台依赖）
├── platform/    # 平台能力接口 + 实现（web/ 已实现，将来 miniapp/ 云开发可另做）
└── ui/          # Vue 3 界面层（可替换）
```

- 前端：Vite + Vue 3 + TypeScript，移动端优先
- 后端：Supabase（PostgreSQL + 匿名登录 + RPC + Realtime + RLS），双人数据全部走 security definer RPC
- 部署：GitHub Pages（`main` = 源码，`gh-pages` = 构建产物）

## 本地运行

```bash
npm install
# 建 .env（共赴功能需要；单人模式不需要）
#   VITE_SUPABASE_URL=https://<你的项目>.supabase.co
#   VITE_SUPABASE_PUBLISHABLE_KEY=<publishable key>
npm run dev
```

数据库初始化：Supabase 控制台 → SQL Editor → 整段执行 [supabase/setup.sql](supabase/setup.sql)（幂等，可重复执行）；并在 Auth 设置中开启匿名登录。

## 部署

```bash
npm run build          # 产物在 dist/
# 将 dist/ 推送到 gh-pages 分支即可（vite base 已配置为 /wandering-planet/）
```
